# Quantum Computing Basics

My first steps learning quantum computing with Qiskit.

## What's in here
- Various Python files exploring qubits, X/H/CNOT gates, and entanglement

## What I learned
- Qubits start at |0> by default
- H gate creates superposition (genuine quantum randomness)
- X gate is a deterministic flip (like classical NOT)
- CNOT creates entanglement between two qubits
- Classical bits store measurement results since qubits collapse when measured
