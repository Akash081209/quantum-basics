# Quantum Computing Basics

A personal learning repository documenting my first steps in quantum computing with Qiskit.

## Structure

- `01-day-1` — first quantum circuits, X gate, H gate, measurement, and CNOT
- `02-day-2` — CNOT variations and the Z, Y, S, and T gates
- `notes` — learning notes and explanations

## Topics Covered

- Qubits and measurement
- Quantum circuits
- X gate
- H gate and superposition
- CNOT gate
- Z, Y, S, and T gates
- Basic multi-qubit circuits
- Running circuits with Qiskit Aer

## Goal

Build a strong foundation in quantum computing and gradually progress toward quantum algorithms, quantum information, and advanced quantum programming.

## Running the Code

Install the required packages:

```bash
pip install qiskit qiskit-aer
```

Then run any Python file with:

```bash
python filename.py
```
